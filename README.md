# 老陈截图 LaoChenShot

纯 **C++ / Win32 + GDI+** 编写的桌面截图工具，**零第三方依赖**（只调用 Windows 自带的系统 DLL），单个 exe 约 450 KB，免安装。

## 直接使用

运行 `build/LaoChenShot.exe`，程序常驻右下角托盘。

> 首次运行如果 Windows SmartScreen 提示“已保护你的电脑”，点“更多信息 → 仍要运行”（自己编译的程序没有数字签名，这是正常现象）。

| 默认热键 | 功能 |
|---|---|
| `Ctrl + Alt + A` | 区域截图（进入编辑） |
| `Ctrl + Alt + F` | 全屏截图（鼠标所在显示器，直接复制） |
| `Ctrl + Alt + P` | 把剪贴板里的图片贴到桌面 |

所有热键都能在 **右键托盘图标 → 设置与热键** 里改，被其他软件占用时会提示。

## 清晰度：让 AI 准确识别文字

设置里的「放大输出」默认是**自动**：普通分辨率屏幕上的小截图（长边 ≤ 1600 像素）复制或保存时按 2 倍高质量双三次放大，再做轻度锐化，小字号的中文笔画更清楚，OCR 和 AI 识别更准。

- 选「原始像素」：1:1 输出，不做任何插值（适合要求像素级精确的场合）
- 选「始终 2 倍 / 3 倍」：字特别小（如 9~11 号字）时用 3 倍效果最好
- 标注（箭头、文字、序号）在放大后的画布上按矢量重绘，不会发糊
- 贴图始终保持原尺寸
- 输出格式默认 PNG（无损）；JPG 按最高质量 100 保存
- 发给 AI 或同事时，尽量直接粘贴或「发送原图」，聊天软件的压缩会让字变糊

## 一键裁边

选好区域后点工具栏的「裁边」按钮（或按 `T`），选区会自动收紧到内容本身：

1. 先去掉四周与背景同色的空白（背景色自动判断，不一定是白色，深色主题也行）
2. 再去掉最外侧 1~3 像素宽的纯色细边框（窗口描边、表格外框）
3. 再去掉边框里面那一圈空白
4. 最后给内容留约 6 像素的窄边，文字不贴边，AI/OCR 识别更稳

不满意按 `Ctrl+Z` 或「撤销」即可还原。四周没有可裁的空白时会弹出提示。

## 截图界面操作

| 操作 | 说明 |
|---|---|
| 拖动鼠标 | 框选区域 |
| 单击 | 选中鼠标下的窗口 / 控件（自动识别） |
| 双击选区 / `Enter` / `Ctrl+C` | 复制到剪贴板并退出 |
| `Ctrl+S` | 另存为 PNG / JPG / BMP |
| `Ctrl+Z` | 撤销 |
| 方向键 | 微调鼠标或选区 1 像素；`Shift+方向键` 调整选区大小 |
| `C` | 复制鼠标处的颜色值（#RRGGBB） |
| 右键 | 取消当前选区；再按右键退出 |
| `Esc` | 退出 |

工具栏：矩形、椭圆、箭头、画笔、荧光笔、马赛克、文字（支持中文输入法）、序号、撤销、钉在桌面、保存、退出、完成。
选中工具后下方出现粗细和 8 种颜色。矩形/椭圆按住 `Shift` 画正方形/正圆，箭头按住 `Shift` 锁定 45°。

## 贴图

拖动移动 · 滚轮缩放 · `Ctrl+滚轮` 调透明度 · `1` 恢复原始大小 · `Ctrl+C` 复制 · `Ctrl+S` 保存 · 双击或 `Esc` 关闭 · 右键更多。

## 设置项

快捷键（3 个）、清晰度（放大倍数、锐化）、保存目录（默认“图片\老陈截图”）、完成后自动保存、放大镜开关、开机自启。
配置保存在 `%APPDATA%\LaoChenShot\config.ini`。

## 自己编译

任选一种：

1. **Visual Studio（推荐）**：打开 “x64 Native Tools Command Prompt for VS”，进入本目录运行 `build_msvc.bat`。
2. **CMake**：`cmake -B out -A x64` 然后 `cmake --build out --config Release`，也可以直接用 VS 打开本文件夹。
3. **MinGW-w64**：运行 `build_mingw.bat`。

## 项目结构

```
src/main.cpp      全部源码（托盘、热键、截图编辑、贴图、设置窗口）
res/app.rc        图标、清单、版本信息
res/app.manifest  Per-Monitor V2 高 DPI + 新版控件样式
res/app.ico       程序图标
```

## 技术要点

- 截图：`BitBlt + CAPTUREBLT` 抓取整个虚拟桌面（多显示器），Per-Monitor V2 DPI 感知保证高分屏像素级清晰。
- 窗口识别：`EnumWindows` + `DWMWA_EXTENDED_FRAME_BOUNDS`（去掉阴影的真实边框），跳过被隐藏的 UWP 窗口，并识别子控件。
- 清晰度：GDI+ HighQualityBicubic 放大 + 3×3 USM 锐化，标注按缩放矩阵矢量重绘。
- 绘制：GDI 双缓冲铺底，GDI+ 抗锯齿绘制标注；马赛克用预计算的像素化纹理画刷，拖动流畅。
- 剪贴板：同时写入 `CF_DIB` 与 `PNG` 两种格式，兼容微信、QQ、Office、浏览器。
